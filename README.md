# 👩‍⚕️ Control de Cuidadoras

¡Bienvenido/a al proyecto **Control de Cuidadoras**! Esta es una aplicación backend desarrollada en **Java** utilizando el framework **Spring Boot** y gestionada con **Maven**. El objetivo principal del sistema es facilitar la gestión, registro y control de cuidadoras de salud o asistencia domiciliaria.

---

## 🚀 Tecnologías Utilizadas

El proyecto está construido con las siguientes tecnologías y herramientas:

* **Java 17** (o superior) - Lenguaje de programación principal.
* **Spring Boot** - Framework para la creación de la aplicación web y API REST.
* **Maven** - Gestor de dependencias y construcción del proyecto.
* **Git & GitHub** - Control de versiones y alojamiento de código.

---

## 🛠️ Requisitos Previos

Antes de ejecutar este proyecto de forma local, asegúrate de tener instalado en tu computadora:

1. **Java JDK** (versión de tu proyecto, ej. 17 o 21).
2. **IntelliJ IDEA** (u otro IDE de tu preferencia).
3. **Git** configurado en tu equipo.
